# ByteBank Expense Tracker

A command-line expense tracker that lets you record, update, delete, and review expenses.

## Features

- Add, update, and delete expenses
- View all expenses or filter by category
- Review totals, averages, and category breakdowns
- Generate a detailed text report
- Save expense data locally in `expenses.json`

## Requirements

- Python 3

## Run

```bash
python byteBank.py
```

Expense data and generated reports are stored in the working directory. They are
excluded from Git so personal financial information is not published with the
source code.
